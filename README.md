# Spotify Songs & Artists – Exploratory Data Analysis and Dashboard

## 📌 Introducción

Este proyecto corresponde al **proyecto final** y consiste en un **Análisis Exploratorio de Datos (EDA)** realizado con Python a partir de dos conjuntos de datos relacionados con **canciones y artistas de Spotify**.

El análisis integra información sobre características musicales (audio features), popularidad, géneros y métricas de los artistas, con el objetivo de **identificar patrones y relaciones entre la música y su impacto en términos de popularidad.**

A lo largo del proyecto se aplican técnicas de **limpieza y transformación de datos, análisis descriptivo y estadístico y visualización de la información**, finalizando con la creación de un **dataset final integrado** y un **dashboard operativo** que resume los principales resultados y conclusiones.

---

## ✅ Requisitos del proyecto

El desarrollo del proyecto contempla los siguientes puntos:

- Transformación y limpieza profunda de los datos
- Análisis descriptivo y estadístico
- Visualización de la información
- Integración de múltiples fuentes de datos
- Elaboración de un informe explicativo del análisis
- Desarrollo de un dashboard que aporte valor
